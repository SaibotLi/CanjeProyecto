# @canjeproyect/web

Frontend de Task 01: React/Vite/TypeScript, React Router, Tailwind, CSS tokens y PWA básica.

Desde la raíz: `pnpm install` y `pnpm dev`. No requiere variables de entorno ni backend.

Rutas: `/`, `/points`, `/rewards`, `/profile`, `/admin`. Todos los datos son ejemplos separados en `src/features/preview/data.ts`.
